## 4. 噪域

| 规则 | 内容 | 来源 |
|---|---|---|
| 出现范围 | **仅第二部分谱面** | 【B】实测 |
| 判定行为 | 触点落入噪域时**完全不判定** | 【B】实测 |
| 可否关闭 | **关不掉** | 【B】实测 |
| 与谱面关系 | **与谱面绑定**（不是全局开关、不是独立机制层） | 【B】实测 |
| 终曲 | **没有噪域** | 【B】实测，`批注.txt` (1) |
| 例外 | 《Leave All Behind》**AT 谱面内有噪域** | 【B】实测，`批注.txt` (2)；该曲不属于第二部分，整理者推测与其"特殊意义"有关，未证实 |
| 在解锁链中的作用 | Ametrine 与 Petrichor 的解锁条件直接以"不因噪域断连击 / 不 miss"为准；ハテ 与 DeSig 的谱面把噪域当作核心玩法 | 【B】`批注.txt` (3)(4)(5)(6) |

**本质**：官方无口径。

> 【F 推测】整理者推测：噪域只存在于像素塔内的黑洞场景中，因此鸠回到现实后的终曲没有噪域。
> 验证方式：需要官方口径，或后续章节中出现同类场景时回看。**不得当作设定转述。**

> ⚠️ 这幅月台图**只**出现在终曲四张曲绘与通关后的开始页上。第一部分地图的「收获」「答案」两个节点缩略图是另外两幅画（人物发色与 Gino／鸠 相符，构图不同），见 [`04_第九章与ARG.md`](04_第九章与ARG.md) §2.1。
