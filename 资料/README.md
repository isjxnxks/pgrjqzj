## 1. 30 秒速览

- 第九章 **穹顶孤舟** 分两部分上线：第一部分 **2026-09-25 17:00**（由源码倒数目标反推），第二部分 **2026-10-02 17:00**（源码明文）。
- **第一部分是六边形网格地图**：总入口分出 Implexrough 线与 Evanescent 线，另有独立的归零分支；收束链 `收获(#17) → 答案 → True Home, True World (Rework) → 第二部分`。6 首曲目，只有 Entrance to the Chaos 与 Exoplanetary Mirage 有 AT 谱面（各 17）。
- **第二部分是 13 节点纵向长卷地图**：7 首曲目 + 6 个异象节点交替（ハテ 与 Desultory Signals 之间不交替）。
- 第二部分七首把当时的难度天花板逐档顶穿，`Desultory Signals` 定数 **EZ 10 / HD 14 / IN 17 / AT 18**。
- 新机制 **噪域**：仅第二部分谱面、触点完全不判定、关不掉、与谱面绑定；**终曲没有**，《Leave All Behind》AT 是例外。**其本质官方无口径**。
- 收集品共 **43 条** = 第一部分 24 + 第二部分 19；五语全文照录在 `06_收集品.md` §2–§3。
- 故事落点：鸠用记忆在塔内造出的"哥哥隼"已被污染并被她放弃；现实的隼死在地面探索队的强震中；鸠回到现实，在中央车站与**早已同行的**吉诺**相认**（不是初遇）。终曲四张曲绘与通关后开始页上**相拥的两人是 Gino 与 鸠**。
- 通关后第九章全部 AT 解锁，开始页变为 `Version : 4.0.1`。
- 游戏外有一条完整 **ARG**：官方 wiki 账号 `D.O.M.E.` 出题，社区解题，终码作为 ACCESS CODE 输入游戏。

## 5. 维护约定

1. **单一事实源**：一段内容只有一处权威写法，其他地方写指针。例：噪域规则只在 `05_第二部分` §4；收集品要点只在 `06_收集品`。
2. **不编造**：**谱师（谱面设计者）**、BPM、时长、未知信号说话人 → 写 **未知**，不写"可能/大概"，不猜数字。**曲师、定数有实测值**，别把两者混为一谈。
3. **过期内容不删**，加 `> ⚠️ **历史记录**：…（已被 X 取代）`。
4. **新增证据先定级再落地**，并在 `07_语料与考据` §4 追加更正条目。
5. **改完跑验收**：`phigros语料包/06_提示词/05_验收清单.md`。
6. **原文照录优先**：43 条收集品的**各语言全文**都在 `06_收集品.md` §2–§3，逐字照录、不翻译、不改写、段间用空 `>` 行分段；其他文件只摘支撑结论所必需的短句并回指编号。
