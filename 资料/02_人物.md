## 2. 关系与原文证据

### 2.1 鸠 ↔ 隼：兄妹（且哥哥已死在现实）
- 【B】#13：`曾经的她，在像素塔中用自己关于"隼"的记忆，制造了一个新的"隼"……不再是她记忆里的兄长，而是一个独立存在的"人"，以至于她不再认识他，甚至放弃了继续维持他的存在。`
- 【B】#32「再见」站台对话：`鸠：【转身，惊讶，呼唤】哥哥！` / `隼：你该走了。` / `鸠：可是我才找到你。` / `隼：分离不过须臾，相信我，人们终会再相见。` / `鸠：在那个，叫现实的世界吗。`
- 【B】#32 收束：`她想起来了，原来自己再也见不到哥哥了。`
- 【B】#19：`隼失踪后，吉诺没有在隼的遗物中找到这个本子。`
- 【B】现实层的死讯：#33 电子早报头条 `地面探索队遭遇强震，致一死多伤`。

> **结论**：塔内的隼是**记忆造物**，现实的隼**已死**。#32 里的这场"再见"因此不是重逢的起点，而是告别。

### 2.2 隼 ↔ 吉诺：搭档（隼为吉诺的顾问，代行先行搜查）
- 【B】#21 原文：`一如既往的，隼承接了先行的搜查工作，当然，是以我的名义，他作为搭档与顾问随行。`（叙述者为吉诺）
- 【B】#20：隼是"年轻的学者"，"在计科学界小有成就"，却"选择了最原始的纸质记录"。
- 【B】#22：隼发现一处约三分之一塌陷的研究基地，`它的内里，数以千计的AI，寄存于各式各样的媒介当中`，并称`在几十年前，是可以的`。
- 【B】保管分配：#19 由**鸠**保管，#20–#22 三条线索由**吉诺**保管——同一件遗物分属两人。

### 2.3 鸠 ↔ 吉诺：塔内早已同行，现实里才相认
- 【B】**塔内同行**：#15–#17 吉诺已是保管单位；#17 里吉诺为鸠检查伤势、鸠在他面前抱着隼的笔记本问`我的哥哥——他是不是来过这里。`——这是**已建立的关系**，不是初见。
- 【B】**现实相认**（#33）：`????：请问……` → `一道熟悉的声音在耳畔响起，将鸠拉回现实。` → `Gino：这是你的蝴蝶吗？`
  - 先声后人；且明写"**熟悉**的声音"。
  - ⚠️ **这是「相认」，不是「初遇」。** 旧稿据 `?????` 推断为初遇，属已知错误（见 [`07_语料与考据.md`](07_语料与考据.md) §4.1-2）。
- 【B】**画面佐证（终曲四张曲绘 ＋ 通关后开始页）**：四张曲绘是同一个连续镜头——新郑州中央车站月台（背景黄色警示牌「注意站台空隙 请勿拥挤」）。**黑发校服、粉袜、蝴蝶发饰的少女＝鸠；浅橙发、深色长风衣的高个＝Gino。** 难度递进 EZ 只有鸠 → HD/IN 两人分立 → **AT 两人相拥**。
  > 所以**相拥的两人是 Gino 与 鸠，不是兄妹**。#32 里那句"再也见不到哥哥"与这幅画不矛盾：告别给隼，相拥给 Gino。整理者已确认此点。
- 【B】**外形速记**（用于以后读图，不要反过来推剧情）：鸠＝黑长直＋校服＋粉色过膝袜＋蝴蝶发饰；Gino＝浅橙/金色短发＋深色长外套。
- 【B】**第一部分地图上的两处人物缩略图**（`地图大致样貌.jpg` 6× 放大后读图）：「收获」节点＝冷色调，黑长直者与一名浅发者在一颗球体之上；「答案」节点＝两张面部特写并列，左浅/金发、右黑发。**两处发色都与"鸠＋Gino"相符**，但构图与终曲月台图不同，**不能**当作同一幅画。逐条对应哪张官方曲绘 → **未知**。

### 2.4 鸠 ↔ 「他」：鸠曾扮作隼去接触
- 【B】#24：`你确实不承认，不然也不会从几百年前起便试图从还未觉醒的他那里找到点什么，还特意扮作"隼"去接触……这种事居然没捅出什么篓子，真是神奇。`
- 【B】#23：`就因为那日那本该出现在门后的身影，由哥哥变为了他？`
- 时间尺度：#24 的「**从几百年前起**」表明塔内跨度以百年计。

> 这两条是"塔里的隼是造物"之外的第二重身份线索：**鸠不仅造了隼，还以隼的身份去接触过另一个人**。#23/#24 的说话者身份**未确定**（见 [`99_未解之谜.md`](99_未解之谜.md)）。

### 2.5 鸠 ↔ 玩家（您）
- 【B】#26、#27 保管单位为「您」，现实层日期 `2091.08.31` / `2092.02.20`。游戏把玩家写进保管链。
