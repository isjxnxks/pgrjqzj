**渲染栈（乱码怎么来的）**
- 主循环 `requestAnimationFrame` 累积时间 `t`；三趟绘制：噪声红点层、字形层、合成层。
- 红点层：色板 `#ff4949 / #ff5454 / #ff2e2e`，网格 `sparkCell=11`、密度 0.22、alpha 0.5；每格用**整数哈希**（`hash(x,y,r) = (mix(x + y*7919 + r*104729)>>>0)/2^32`）判决，`h%10>6` 跳过约三成；**时间种子 `t*12|0`** → 每秒变 12 次。
- 字形层：`fillText` 多遍 —— 先 `shadowBlur=48` 的黑色描边，再 `rgba(255,45,45,.5)` 与 `rgba(60,200,255,.5)` 两遍**红青错位**（经典故障艺术）。
- 查询参数 `?black` / `?nobg` 会切低配（`cellPx=8`、`speed=0.22`、`sparkCell=11`、`bigDensity=0.03` 等）。
- **全脚本 `Math.random` 0 次、`crypto` 0 次** → 画面是「时间 + 图像数据」的确定性函数：**"乱码"不是密文，是确定性噪声动画**（可复现、可离线重放）。
