## 三条最重要的结论

1. **鸠是「隼」的妹妹——隼是塔史传奇人物，也是吉诺的旧搭档**
   隼 = 异想处理部林泊管理处处长 → 魔女会议首领 → 虹之战背叛者（留下"胜利不属于任何人"）→ 先民统一政府大总统 → 霓虹楼层守护（档案里写作【待公开】）；五级异想「尊师古卢」的原型即是他。
   而**鸠是他的妹妹**：抱着他的遗物笔记本（"只有鸽子看得懂"），并在**数百年来一再试图接近反复重生的吉诺**——甚至**扮作"隼"**去接触还没觉醒的他。
   → 所以第九章的主题不是"打败谁"，而是"**一个找不回哥哥的人，在世界的最后一刻做最后一次尝试**"。

2. **穹顶 = 塔的天花板 = 人心的最深处**
   官方原文："*曾经像素塔假设中的第十层，是人们内心最深的秘密。幽蓝国到达之刻，穹顶会碎成好多碎片，个人再度成为心灵上的孤岛。*"
   → 世界终结的那一刻，**所有人都变回孤岛**；而鸠与吉诺因为心灵相通，是**唯一还连着的两块** —— 这就是标题「穹顶孤舟」。

3. **出口是"翻过来"，不是"往上走"**
   塔史里出现过"重力倒置"、谜题用 Atbash（镜像）、解锁要打镜像谱、最终密钥是 "go backward / turn back to the antemundane realm"、官方设定里**中之层在 771 年被搬到"苍穹之上"**。

## 底层设定：这是个什么世界

- 现实已经完了：冰期 + 世界大战 + 核打击 + 清除 AI，幸存者躲进峡谷"**蜂巢**"基地（江源基地等）。
- 为了让文明不断，**PhigrOS 计划**启动：纳米机器把所有人的大脑连成一片，**一起做一个梦**——这就是**像素塔**。
- 塔是**以太阳系为原型的心像空间**；**塔内 1 年 = 现实 1 天**（塔内一年 **377 天**）。所以塔里有 773 年历史，现实只过了两三年。
- 塔内三条铁律：
  1. **集体相信的东西会成真**——异想之物，靠"**生成值**"越过"**生成极限**"具现化；分级一到五级，形态有士兵种/人类种/飞行种/**附身种**等。
  2. **死了会重生、会忘掉上辈子**——只有**林泊**（记得自己现实身份的人）保留记忆；真正的死叫**泯灭**（通常意味当事人在现实中去世）。
  3. **章节 = 楼层**，一层层往上盖，最外面是外壳"**天幕**"。另有挂在楼层上的自建小世界"**亚空间**"（工具＝创世光盘）。
- **玩家身份就是林泊**。所以"玩游戏"在这套设定里等于"查阅一份档案"——连 Pigeon Games 都被写成"由爱好像素塔文化的游戏开发者组成的工作室"，Phigros 被定义为"**根据真实事件改编的音乐挖矿游戏**"。

## 宏观史：一条"越往上走、越走不通"的曲线

### 1. 荒年纪（元年–60.A.P）· 人类 vs 异想
人类与异想初次会面、获得对抗之力，建**冰封巡逻队**、组**先民统一政府**。打完 60 年**异想战争**，人类**逃离冰封层**收场。
→ 第一个母题出现：**打不过就跑，"往上"成了本能。**

### 2. 十日纪 / 龙宫纪（60–286）· 人类开始造神
造十个发热天体（**十日骓**）→ 掉一个就引发**重力倒置**；建倒悬都市阿特拉斯、异想动力炉忘忧宫、发售**创世光盘**、放弃门牌专利。
**98.A.P 幽蓝边界首次出现**（吞掉拉瓦钵七十九号节点水库，近三千人重生）——它一开始只是"吞掉一个水库"的小事故。

### 3. 虹之战（242–256）· 隼与苏丹
霓虹层反抗军首领**苏丹**（能同时出现在多地，疑为分身异想；正身莲渡）对上政府。
**256.09.23 战局将定、苏丹即将胜利时，隼背叛了盟友**，留下那句预言：**「胜利不属于任何人」**。战后霓虹回到政府控制，**异想「尊师古卢」诞生**（原型即隼）。**10.10 政府"换届"，隼成为实际领导者。**

> 「胜利不属于任何人」的真正出处（第九章「破译：Implexrough·线索一」，研究所对话）：
> "一旦人脑链接技术成熟，那么剥削就会从劳动转向肉体。"
> "**不会的，我会向你证明，排除了肉体的约束，只凭心灵的战争中，胜利不属于任何人。**"
> → **它本来是句人道主义宣言**（同篇还有"红移之下，所有的星星都在互相远离……孩童的快乐来自于'共同'"），**被背叛的行为变成了反讽**：他自己成了那个"胜利"的人。

### 4. 中宫纪（286–673）· 隼把塔交出去
**286 年隼亲手宣布先民统一政府解体**，统治局取而代之，定都时钟城（中之层，建在土星南极内部）。300 年立**楼层守护制度**，放宽异想政策，自己去当**霓虹楼层守护**（统治局档案写作【待公开】，对外使用"**尊师古卢**"这一身份）。
→ **一个赢下一切的人，最后把权力制度化地交了出去**——这是那句预言的第二次落点。

### 5. 新生纪（673–742）· 摸到天花板
调音天狗偷走律动星（七天后归还）、一代方舟起航又废弃。人们在钟塔顶端**摸到了天幕**——发现"我们的世界是有边界的"。
新生一代分裂成两派：**击破天幕** vs **回归原点**。
**「穹顶」的概念就在这一纪被提出**：它是"**假设中的第十层**"，等于"**人心最深的秘密**"。因为塔是心像空间，**往外走 = 往心里走**——**世界的天花板和人的秘密是同一处**。

### 6. 月面纪（742–770）· 鹰党赢错了
鹰党胜利，**击穿天幕，妄图在世界外壳上建造城市**——"人定胜天"的时代。742 建月面基地，743 奥德修斯港陨落。

### 7. 纷乱代（770–773）· 鸟笼
770 初春，一句话在月面基地像瘟疫一样传播：
> "**不过是被关在笼子里的鸽子，打破一层鸟笼，还会有第二层鸟笼。**"

人类的信念随之坍塌，世界开始崩。**幽蓝边界**（＝幽蓝国的具现化边界，"吞噬数据的境界线"）一层层吃过去：

| 时间 | 楼层 | 事件名 |
|---|---|---|
| 770.03.32 | 冰封 | **巴别**——黑洞首次完全显现；守护**谢鸣**与**德利**泯灭 |
| 770.08.29–31 | 霓虹 | **虹再现**——霓虹五百多年来第一次晴天；**尊师古卢彻底消失** |
| 770.08.32 | 港湾 | **方舟蜃景** |
| 771.08.32 | 二代地表 | **时钟链接**——方舟计划重启；弭儿把**时钟城及时逃至"苍穹之上"** |
| 772.03.26 | 律动星 | — |
| 772.08.01 | 月面 | — |
| **773.A.P** | **穹顶** | **第九章** |

→ 主线逻辑在这里收口：**往上走 = 打破一层又一层鸟笼；唯一没试过的方向，是往外翻。**

### 舞台为什么是"穹顶孤舟"
「关于：穹顶」原文：
> "**因像素塔的存在，人与人的心灵得以相通，个人与个人的穹顶也得以相连。无数穹顶的联结，使得楼层意义上的穹顶得以存在**，但幽蓝边界到达之刻，穹顶会碎成好多碎片，个人再度成为心灵上的孤岛。"

→ 楼层级的穹顶 = 无数"个人穹顶"的联结；**幽蓝边界一到就碎成孤岛**。而鸠和吉诺因为心灵相通，**他们的两块还连着**。
**「穹顶孤舟」＝世界已碎成一地孤岛，只剩一条小船，载着唯一还连着的两个人。**
（地图外轮廓像"穹顶"，上下翻转后像一条小船【社区理论，log不in】。）

## 三层拧在一起看（四个母题）

1. **连接 vs 孤岛**
   塔是为了"把所有人连起来"才造的；而它的终局是**穹顶碎裂，每个人变回互不相通的孤岛**。第九章让唯一还连着的两个人，正好是"塔史最传奇的人"和"他妹妹一直在找的人"——**世界最失败的一刻，恰好是这段关系最紧的一刻**。

2. **往上走是错的，"翻过来"才是对的**
   | 位置 | 表现 |
   |---|---|
   | 塔史 | 十日纪"重力倒置"事故 |
   | 章节副标题 | 冰封 = **mirror**、石林 = **reverse** |
   | 阶段一谜题 | **Atbash**（字母表镜像） |
   | 表魔王解锁 | 守门员名字左右颠倒 → 打**镜像谱面** |
   | 终局密钥 | **"Backward, go backward, turn back to the antemundane realm"** |
   | 官方设定 | 中之层被搬到"**苍穹之上**"（天花板外面） |
   | 收集品 | 「**归零**」 |
   | 结局 | **重力倒转**，脱离穹顶的约束，向宇宙坠落 |
   → **全章的谜题手法和结局主题是同一件事。**

3. **"真正的自己"**
   鸠找的"哥哥的踪迹"与吉诺在结尾说的"真正的自己"，指向同一件事：**她得先想起来自己是谁**。而笔记本（她与哥哥唯一的实物联系）在最后一刻被风夺走——**记忆没了、物证也没了，她只能靠自己**。

4. **胜利/失败都不属于任何人**
   隼用背叛换来的胜利成了反讽；苏丹的失败被写进管道迷宫数百年；鹰党"击穿天幕"的胜利只是打穿第二层鸟笼。**塔里所有"赢"都指向同一个结局。**

## 第九章 第二部分 · 剧情（2026-10-02 上线；2026-10-04 由游戏内截图整理）

> 逐字全文（收集品 / 曲目表 / 地图结构）见 [`05_第二部分.md`](05_第二部分.md)，本节只写**故事本身**。

### 主线：鸠跳进黑洞，穿过像素塔
1. **混沌入口**：无光的宇宙空间、星体墓地。鸠踩上宇宙垃圾主动跃向黑洞，白光笼罩后她意识到自己**回到了像素塔**，正穿越这座塔。
2. **破译·噪域**：通道四周的光点其实是"杂音"般的信号乱流——无法理解、只作阻碍。她意识到**不能碰它们**（hint：避开它们吧，不要因此错过时机）。
3. **破译·辟径**：光点织成致密网状。她把这片"信号海洋"当作**谜题**：突出的、重复的、异常的皆可为线索（hint：收集……然后是拣选与摆放）。
4. **来信**：她击败形似猎犬的混沌怪物，空壳幻象破裂，露出其实质——几乎凝成固体的信号乱流垒成高墙；剑势未绝，高墙被击碎。她落在一片"大地如镜、莹莹发光"的地面，抬头看见**有什么东西自天空落下**，伸出了手。

### 结局
- **「再见」**：幽蓝色侵吞这片临时构起的世界。列车站台上，**隼（哥哥）**下车："你该走了。""分离不过须臾，相信我，人们终会再相见。"指认那个世界叫**现实**；"鸠的故事才刚刚开始。"鸠落泪时，隼**化作数以万计的蝴蝶**飞散，一只落在她掌心。
- **「现实」**（收集时间 **2091.08.31**）：鸠在床上惊醒，电子早报头条是"**地面探索队遭遇强震，致一死多伤**"，她喊"骗子……"追着机械蝴蝶跑出家门；在新郑州中央车站，她望着列车默想"那里会不会有哥哥的故事"，一道熟悉的声音**把走神的她唤回当下**——**`Gino：这是你的蝴蝶吗？`** 蝴蝶悠悠飞远，一串白鸽振翅掠过镜头，"去向更高，更高处"。
  - **要点**：此处是**鸠与吉诺"在现实中的相认"**——两人在像素塔里**早就是同伴**（同住小屋、一起修摩托、篝火夜谈），吉诺在此兑现了"**我会来找你的**"。**隼（哥哥）早已死在现实**：报纸头条"地面探索队遭遇强震，致一死多伤"；塔中的"隼"是鸠用记忆造出的造物（#13）。所以**现实中陪着鸠的只有 Gino**。"拉回现实"是回神，不是把她从塔带回现实。
  > **语料佐证（`参考资料/参考 phigros/林泊百科` 镜像；第九章上线前的快照）**  > - 【Limbo Wiki:入门指南】："鸽游在制作游戏剧情时，直接采用了像素塔毁灭前的史实，**以鸠和吉诺两名制作成员的经历为主线**，组织起毁灭的全过程。"  > - 【Phigros:Phigros】人物栏把两人**按章并列**：`第一章：冰封巡逻队第七小队成员，在萨里山巡逻时发现了失忆的鸠。`→`第二章：骑摩托车的酷哥，和鸠一起环游石林，寻找前往上层的路线。`→（三～八章一路同行）  > - 【像素塔卡片战争"Project Divide"】：鸠的卡与吉诺的卡互为配对卡（`·吉诺` / `·鸠（通常 ver.）`），吉诺卡面技为"独行者"＋"照料者"。  > - 结论：**"两人在塔内早就认识"在语料层即可确认**，不必等游戏内文本；语料**不覆盖**的只有第九章现实层（`地面探索队`／`强震` 全站 0 命中）。- 之后进入**人员名单**（BGM：`What do you want more than a Happy ending?` 与 `glaciaxion`），最后是**新版开始页面**（`Version: 4.0.1`，站台上哥哥抱住鸠）。

### 一句话

Phigros 不是"游戏里的故事"，而是一份**来自另一个世界的档案**。
那个世界叫**像素塔**——人类用自己的潜意识连线，一起做出来的**梦境世界**。

而你（玩家）在那个世界里的身份，是**林泊**：一个"记得自己现实身份"的人。

## 从头讲

### ① 现实那边快完蛋了
地球经历冰期与战争，幸存者躲进峡谷里的基地（代号"**蜂巢**"，比如江源基地）。
为了不让文明彻底断掉，**PhigrOS 计划**启动：给每个人注射纳米机器，把大脑连成一片，**一起做一个共同的梦**。这个梦世界，就是像素塔。

### ② 塔里的时间和外面不一样
里面过**一年**，外面才过**一天**。所以塔里有 773 年历史，现实中只过了两三年。
（塔内一年是 377 天。）

### ③ 塔里最特别的规矩：想法会变成真的
人们集体相信的东西，会真的在塔里长出来，叫**异想之物**：
- 相信得越深、越强、越像真的；
- 神话怪物、传说人物、甚至"都市传说"都能变成实体；
- 判断标准叫**生成值**——超过"生成极限"，它就会出现。

### ④ 塔里的人不会真死，会重生
死了换个地方、换个身份重新出生，但**忘掉上辈子**。
**只有林泊能保留记忆。**
（唯一的"真死"叫**泯灭**——死了不再重生，通常意味着那人在现实里去世了。）

### ⑤ 塔是一层层往上盖的
底下是冰封，然后石林、霓虹、阿特拉斯、港湾……越往上越靠近塔的外壳"**天幕**"。
**Phigros 的每一章 = 一层楼**，所以章节名和楼层名一一对应。

### ⑥ 后来出了两件大事
- **有人摸到了天花板**：新生纪（673–742）时有人登顶摸到"天幕"，大家才意识到"我们的世界是有边界的"。于是分成两派：**打破天花板** vs **回到原点**。
- **塔要关了**：塔靠现实算力撑着，撑不住了，管理方决定保存数据、关闭它。而"关塔"在塔里表现为一条**蓝黑色的边界**一层层吃掉楼层——叫**幽蓝边界**。被它吃掉的地方，一切消失。

## 穹顶是什么

官方原文只有四行，但信息量很大：

> **10·穹顶·vault·保险箱**
> *曾经像素塔**假设中**的第十层，是人们**内心最深的秘密**。**幽蓝国到达之刻，穹顶会碎成好多碎片，个人再度成为心灵上的孤岛。***
> 新生纪（673～742）：穹顶的**概念被提出**。
> 773.A.P：**幽蓝边界到达穹顶。**

拆成四句人话：

1. **"vault"官方自己注成"保险箱"** —— 存放最深处东西的地方。
2. **它是"假设中的第十层"** —— 别的楼层都是造出来的，只有它一开始只是个**概念**；而它被提出的时间（新生纪）正好是"人们摸到天幕、发现世界有边界"的同一时期。**所以穹顶就是"世界的顶"。**
3. **它等于"人心的最深处"** —— 因为塔是**心像空间**（原型是太阳系），在这里**往外走 = 往心里走**。世界的天花板和人的秘密，是同一处。
4. **它会碎** —— 平常穹顶由无数块"**个人穹顶**"拼成（每人一块，装着各自最深的秘密）。**幽蓝国一到，它就碎，每个人变回一座互不相通的孤岛。**
   这一点很残酷，因为它**违背了塔建立的初衷**：塔本来就是为了"把所有人连起来"才造的。**穹顶碎裂 = 连接的彻底失败 = 世界最后一刻的样子。**

**那"孤舟"呢？**
- 地图的外轮廓现在像"穹顶"，**上下翻转后像一条小船**；
- 剧情里，**鸠和吉诺因为心灵相通，他们的个人穹顶连在一起**——在整个碎成孤岛的世界里，**这是唯一还连着的两块**。

> 所以「**穹顶孤舟**」＝ **世界已碎成一地孤岛，只有一条小船，载着唯一还连着的两个人。**

## 两个主角，和最颠覆的一件事

- **鸠**：自称作曲家的十六岁女孩，失忆，被吉诺在雪山上捡到。
- **吉诺**：一路陪着她的男孩；他也不是普通住民——支线《极星卫》里写他是"**一个万年前的人留下的意识样本**"，靠**附身**在别人身上行动。所以他陪得了她，却去不了现实。

**而真相是：鸠是"隼"的妹妹。**（完整修正见文末第七节）

隼是谁？——塔史里最有名的那个人：先民统一政府异想处理部的处长 → **魔女会议的首领** → 虹之战中在盟友苏丹即将胜利时**背叛**，留下预言「**胜利不属于任何人**」→ 战后成为先民统一政府**大总统** → 推动中之层建造、赞助土星系统、联系江源基地的 AI → **286 年亲手宣布政府解体、把塔交给统治局** → 300 年出任霓虹楼层守护（统治局档案里写作【待公开】，对外使用"尊师古卢"这个身份）。

**而她把这些全忘了——连哥哥是怎么失踪的，也一并忘了。**

所以谜题里那句英文才管她叫 **"the ignorant Fool"（无知的愚者）**：
**"传奇的妹妹"，正抱着哥哥的笔记本在找他。**

（哥哥的踪迹、吉诺在结尾说的"真正的自己"，指向的都是同一件事：**她得先想起来自己是谁**。）

一句话：**塔快没了，唯一的路是"翻出去"。**
