## 关键事件：巴别（＝第九章那张黑洞图的来源）

**Phigros:巴别**（770.03.22–03.32，纷乱代开端）

1. **魇魉军团**从深坑爬出，迅速攻破第一到第八巡逻队防线；
2. 深坑爬出第二波兵力，消灭了第一波魇魉；随后**洞内伸出多条巨大黑爪**把士兵拽回去；
3. 深坑顶部出现一个**小点，缓慢上升扩大到圆盘大小，产生强大吸力**——连补给和昏迷的同伴都被吸走；
4. 先民通过卫星看到**虫洞**生成，尝试一周未能阻止扩散；
5. **770.03.32 虫洞扩张到极限，全力吸收地面物质**；先民使用备用动力逃离；
6. 事后录像显示：**冰封层就此消失，虫洞仍在上升，不日将到达第二层。**

**阵亡名单（已确定）：Dlyro、谢鸣。**

> 对照官方《幽蓝国》条目："**幽蓝边界的完全显现，即冰封地区层巴别事件中出现的黑洞，标志着纷乱年代的正式开始。**"
> → **第九章那张黑洞图，就是这个虫洞。**而幽蓝国是"所有记忆的最终归宿"，所以剧情里那句"**黑洞会让你看见过去**"才成立。

## 核心机制

**异想之物（Whims）**
- 人类（"因果体"）的幻想被抽象、积聚后，**生成值**超过**生成极限**，就会"异想污染"出实体。
- 分级：一级无害 / 二级少量 / 三级产生幻想造物 / 四级有自主意识 / **五级智力等同先民**。
- 形态分类：士兵种、人类种、养殖种、静物种、污染种、下品种、**飞行种**（可跨楼层）、**附身种**（附着污染源、会改变被附身者形态）。
- 来源分类：拟真异想（恐惧与期盼）、人造异想、**分身异想**（因重生或自我分裂诞生；官方举例：清醒者日报特约作者 **LeaF**）。
- 幻想造物生成三原则：必须"借用"已有概念 → 必须有集体认可的表象 → 必须考虑具现化后的影响范围（例：弭儿借用了"撒母耳"与"诺亚"，被赋予职能【方舟领航员】）。

**重生（Rebirth）**
- 住民死后在任意安全点重生，**身份识别码可能改变**（先民/异想/AI），**失去记忆；只有林泊能保留上一代记忆**。灵魂总数不变。
- 重生点可被"锁定"：纷乱代所有人被锁定在港湾（港湾毁灭后改月面）。
- **"新生纪后，可以把重生地点锁定在穹顶，但此法极少人知道。"**

**泯灭（Annihilation）**：死后**不再重生**。林泊普遍认为代表当事人在现实中死亡；新说认为还需"个体社会关系完全瓦解"。

**回收（Recycling）**：霓虹居民寿命像钱一样存在系统里，违规扣减，扣光即被**回收**——对应**霓虹灯牌熄灭**；熄灭的灯牌回厂换名字，再交给当天出生的人。

**缓存物质**：一级异想，异想的初级物质态；可作能源；极容易被一个念头变成污染。衍生形态：脂球、**宫城雪**（阿特拉斯深海的"雪"）。

**幽蓝国 / 幽蓝边界**
- 幽蓝国 = **像素塔的底层逻辑，所有记忆的最终归宿**（龙宫纪童谣：名为"鲲"的异兽把人带到此处）。
- **管道迷宫** = 幽蓝国的出口之一（失去自我的人类与亡灵徘徊其中）。
- **幽蓝边界** = 幽蓝国与其他空间交界的特征，具现化即"吞噬数据的境界线"。
- **幽蓝边界的完全显现，就是冰封层巴别事件中出现的黑洞**（＝第九章那张图）。

**亚空间**：人们自建的小世界，挂靠在楼层上（模拟社会、幻想作品亚空间化、自住住房、大事件复刻、私人仓库、**记忆宫殿**）。制作工具：**创世光盘**（莫比乌斯工作室）。
创世光盘破损后的已知问题：绝对私人 / 亚空间失联 / 盗窃 / **游客寄生** / **镜中镜**（互嵌无限循环→主脑死亡）/ **围困**（进入后与像素塔永久断连）。

**其他技术**：十日骓（十个近地卫星，"十日凌空"传说的来源）；忘忧宫的**旧型能源发生器**（吃异想产能，也能**消耗能量制造异想**＝逆生成，隐患由克洛诺斯发现）；土星系统；PhigrOS。

> "曾经像素塔假设中的第十层，是人们内心最深的秘密。**因像素塔的存在，人与人的心灵得以相通，个人与个人的穹顶也得以相连。无数穹顶的联结，使得楼层意义上的穹顶得以存在**，但幽蓝边界到达之刻，穹顶会碎成好多碎片，个人再度成为心灵上的孤岛。"
