## 这是什么

- 一份**游戏内一手文本的整理**：收集品原文按 Unity 字符串结构从 APK 解包取得，并用游戏内截图逐条校对（15 条字段自动比对，**0 处不符**）。
- 一份**带来源分级的考据**：官方层 / 游戏内实测 / wiki 语料 / 社区 / 推测 分开标注，不混排。
- 一个**零构建的在线查看器**：目录、全文搜索、大纲、深链、明暗主题，手机平板可用。

## 这不是什么

- ❌ 不是官方资料。本站是爱好者整理，游戏内容版权归 **Pigeon Games（鸽游）** 所有。
- ❌ 不做 ARG 解密。倒计时页密文的处理方是**社区解密群**，本站只做**登记与存档**。
- ⚠️ **含完整剧透**，含未在游戏内取得条目（「自白·其三」）的原文。

## 方法与可复现性

- **正文来源**：`base.apk` → `assets/bin/Data/data.unity3d`（167.9 MB → 解出 **520.2 MB**）。UnityFS 布局要点：`flags & 0x200` 表示 blocksInfo 前补 16 字节对齐；数据块按各自 `flag & 0x3F` 处理（`0` 未压缩 / `2,3` LZ4 / `1` LZMA）；正文按 `[u32 长度][数据]` 逐串切出。
- **校验**：43 条条目的**收集时间 / 保管单位 / 等级**与游戏内截图 15 条比对 **0 处不符**；43 条正文指纹**互不重复**。
- **已知更正**：早期曾误判包体"自定义加密"、曾据 `?????` 误读为"初遇"、曾把第二部分收集品数写成 23 条 —— 均已更正，明细见 `07_语料与考据.md` 的「更正记录」。
